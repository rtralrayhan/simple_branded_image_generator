# Simple Branded Image Generator

A lightweight browser-based tool for turning ordinary photos into branded halftone-style artwork using custom color palettes, pattern variations, and export-ready downloads.

## Live URL

https://rtralrayhan.github.io/simple_branded_image_generator/

## Why this matters for brand designers

Brand designers often need quick visual mockups that feel polished, consistent, and on-brand without waiting on a full design pipeline. This tool helps by making it easy to:

- test how a photo looks with different brand tones
- create social-ready or presentation-ready branded visuals fast
- produce a stylized halftone look that feels premium and intentional
- iterate on color and pattern decisions in real time
- export final artwork without needing complex design software

It is especially useful when you want to explore creative directions quickly while keeping a strong brand identity in the visual language.

## Features

- Upload a photo from your device
- Apply dots or line-based halftone patterns
- Adjust density and texture for different visual effects
- Switch between curated brand color palettes
- Customize ink and base colors manually
- Preview changes instantly in the browser
- Export the final artwork as a PNG download
- Works as a simple static site with no backend required

## Best use cases

- Brand concept mockups
- Social media artwork
- Marketing campaign visuals
- Presentation graphics
- Product promo styling
- Fast design exploration before final production
